# ИИ: привязи для волов

Обычно ИИ строит до 3 привязей для волов на каменоломню. Кроме того, он автоматически ставит привязь при каждой постройке или повторной постройке каменоломни.

Эти автоматические привязи могут исчерпать вместимость жилья ИИ и остановить появление новых крестьян. Расширение позволяет отключить их и настроить правила строительства дополнительных привязей.

**Связанная привязь** относится к каменоломне, откуда её работник в последний раз забирал камень. Эта связь обновляется динамически, а не задаётся раз и навсегда.

## Возможности
- Разрешить больше 3 привязей для волов на каменоломню
- Настроить правила принятия решений о строительстве дополнительных привязей
- Настроить правила для каждого ИИ через AIC

## Параметры AIC

### `AIOxTethers_Logic`
0: Исходная логика игры.
1: Динамическая логика с указанными ниже пределами и правилами нагрузки по камню.

### `AIOxTethers_MaxOxTethers`
Общий предел привязей для волов на игрока.

### `AIOxTethers_DynamicMaxOxTethers`
Общий предел привязей = это значение × число каменоломен.
В любой момент действует меньший из 2 общих пределов.

### `AIOxTethers_ThresholdStoneLoad`
Если `камень/связанные привязи` у каменоломни превышает это значение, строится ещё одна привязь с учётом пределов. Если связанных привязей нет, используется непосредственно количество камня.

### `AIOxTethers_DisableInitialOxTether`
0: Автоматически ставить привязь при каждой постройке или повторной постройке каменоломни.
1: Отключить эту автоматическую установку.

Эта настройка не зависит от динамической логики и её пределов.

### `AIOxTethers_MinimumOxTethersPerQuarry`
Если с каменоломней связано меньше привязей, чем указано здесь, строится ещё одна независимо от нагрузки по камню, с учётом общего предела.

### `AIOxTethers_MaximumOxTethersPerQuarry`
Предел связанных привязей, строящихся для каменоломни в зависимости от нагрузки по камню. Минимум не должен превышать этот предел.
